# תיאום פגישות – אפליקציה בסגנון Doodle

אפליקציית ווב לתיאום פגישות מרובות משתתפים. עובדת בדפדפן במחשב ובנייד, ואפשר גם "להתקין" אותה למסך הבית בטלפון.

## מה יש באפליקציה

- **ניהול משתמשים** – רק מנהל (ADMIN) פותח משתמשים. אפשר לשלוח למשתמש את פרטי הכניסה במייל, לאפס סיסמה, להפוך למנהל ולמחוק.
- **כניסה מאובטחת** – אימייל + סיסמה. בכניסה הראשונה המשתמש מחליף את הסיסמה הזמנית.
- **יצירת סקר** – נושא, מיקום והערות; בחירת תאריכים בלוח שנה; לכל תאריך אפשר להוסיף שעות (או להשאיר "כל היום"); כפתור להעתקת השעות לכל התאריכים.
- **משתתפים לפי אימייל** – כל משתמש רשום יכול להזמין כל כתובת אימייל, גם של אנשים בלי חשבון. יש השלמה אוטומטית ממשתמשי המערכת והדבקה של כמה כתובות יחד.
- **קישור אישי** – כל מוזמן מקבל קישור אישי שמאפשר לו לענות **על הסקר הזה בלבד**, בלי חשבון וסיסמה. הקישור לא פותח שום דבר אחר במערכת. מוזמן שאיבד את הקישור יכול לבקש אותו שוב במייל מתוך הקישור הכללי.
- **שליחה** – כפתור "שליחה במייל" ששולח לכל המשתתפים, או קישור להעתקה / פתיחה בתוכנת המייל שלכם.
- **הצבעה** – המשתתף נכנס מהקישור האישי (או מתחבר, אם יש לו חשבון), רושם את שמו ומסמן לכל מועד: מתאים / אולי / לא. במחשב – טבלה בסגנון Doodle; בנייד – כרטיסים עם כפתורים.
- **תוצאות** – ספירה לכל מועד, סימון המועד המוביל, מעקב מי ענה ומי עוד לא.
- **סגירה** – יוצר הסקר קובע מועד סופי ויכול לשלוח עדכון במייל לכולם.
- **סוכן AI** – כשכל המשתתפים ענו, הסוכן בודק את התשובות:
  - אם יש מועד שרוב המשתתפים סימנו "מתאים" – הוא קובע אותו, סוגר את הסקר ושולח לכולם **זימון ליומן** (קובץ ics שמתווסף ל-Outlook / Gmail / Apple, וגם קישור ל-Google Calendar).
  - אם אין רוב – הוא שולח ליוצר הסקר מייל עם סיכום התשובות, הסבר והצעות, ומבקש להוסיף מועדים. אחרי הוספת מועדים המשתתפים מקבלים עדכון, והסוכן בודק שוב כשכולם עונים.

## איך הסוכן מחליט

- "רוב" = יותר ממחצית המשתתפים (המוזמנים + מי שענה דרך הקישור) סימנו "מתאים". למשל: 3 מתוך 5, 2 מתוך 3.
- הכלל הזה מחושב בקוד ולא נתון לשיקול דעת המודל, כך שההחלטה תמיד צפויה. אם המודל מחזיר תשובה שלא עומדת בכלל – היא נדחית.
- Claude משמש לבחירה בין כמה מועדים שעומדים בכלל (לפי "אולי" ולפי ההערות של המשתתפים), ולכתיבת ההסבר וההצעות בעברית.
- בלי `ANTHROPIC_API_KEY` הסוכן עדיין עובד – לפי הכלל בלבד, עם הודעות קבועות.
- מועד שמשתתף לא סימן נחשב "לא מתאים". "כולם ענו" = כל משתתף סימן את כל המועדים.
- יוצר הסקר יכול לכבות את הסוכן לסקר מסוים, או להפעיל אותו ידנית ("הפעלת הסוכן עכשיו") גם לפני שכולם ענו.
- הסוכן רץ פעם אחת בכל סבב. הוספת מועדים פותחת סבב חדש.

## הפעלה במחשב (לבדיקה)

צריך [Node.js](https://nodejs.org) גרסה 22.13 ומעלה (מסד הנתונים מובנה ב-Node, אין צורך בהידור או ב-Visual Studio).

```bash
npm install
cp .env.example .env      # ומלאו את הפרטים
npm start
```

פתחו את http://localhost:3000 והתחברו עם ADMIN_EMAIL ו-ADMIN_PASSWORD.
אם לא הגדרתם סיסמת מנהל, היא תודפס בחלון השרת בהפעלה הראשונה.

כל עוד SMTP לא מוגדר, המיילים לא נשלחים אלא מודפסים בחלון השרת – נוח לבדיקות.

## הגדרת שליחת מיילים עם Gmail

1. בחשבון Google הפעילו אימות דו-שלבי.
2. היכנסו ל-https://myaccount.google.com/apppasswords וצרו "סיסמת אפליקציה".
3. ב-.env: `SMTP_HOST=smtp.gmail.com`, `SMTP_PORT=587`, `SMTP_USER` = כתובת ה-Gmail, `SMTP_PASS` = סיסמת האפליקציה.

לכמויות גדולות עדיף שירות ייעודי (SendGrid, Mailgun, Brevo) – כולם נותנים פרטי SMTP שמכניסים באותם משתנים.

## העלאה לאינטרנט

האפליקציה היא שרת Node.js אחד עם מסד SQLite בקובץ, כך שמתאים כל שירות שמריץ Node ושומר קבצים:

- **Render.com** – New → Web Service, חברו את הקוד, Build: `npm install`, Start: `npm start`. הוסיפו Disk וכוונו אליו `DATA_DIR` (אחרת הנתונים יימחקו בכל עדכון). הגדירו את משתני הסביבה מ-.env.example.
- **Railway / Fly.io** – אותו עיקרון: Volume ל-`DATA_DIR` ומשתני סביבה.
- **שרת VPS** – `npm install && npm start` מאחורי Nginx עם HTTPS, ו-pm2 להרצה קבועה.
- **Docker** – מצורף `Dockerfile`: `docker build -t meetings . && docker run -p 3000:3000 -v meetings-data:/data --env-file .env meetings`

חשוב: הגדירו `BASE_URL` לכתובת האמיתית, כדי שהקישורים במיילים יפנו למקום הנכון, והשתמשו ב-HTTPS.

## מבנה הקבצים

```
server.js        שרת ה-API: התחברות, משתמשים, סקרים, הצבעות
db.js            מבנה מסד הנתונים (נוצר אוטומטית)
mailer.js        תבניות המייל והשליחה
agent.js         סוכן ה-AI: בדיקה אם כולם ענו, החלטה, זימון או בקשת מועדים
calendar.js      יצירת הזימון ליומן (ics) וקישור ל-Google Calendar
public/          האפליקציה בדפדפן (HTML, CSS, JavaScript)
data/app.db      מסד הנתונים (נוצר בהפעלה הראשונה – גבו אותו)
```

## אבטחה

סיסמאות נשמרות מוצפנות (bcrypt), העוגייה מוגנת (HttpOnly, SameSite), יש הגבלת ניסיונות כניסה והגנה מפני בקשות מאתרים זרים. רק מנהל יכול לפתוח משתמשים, ורק יוצר הסקר (או מנהל) יכול לשלוח, לסגור או למחוק אותו.
